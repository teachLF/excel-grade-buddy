📋 خطوات الاستخدام

▶️ الخطوة 1: إعداد قاعدة البيانات
   1. افتح Supabase Console
   2. اذهب إلى SQL Editor
   3. انسخ ملف: supabase/migrations/20260901_create_announcements_table.sql
   4. قم بتنفيذ الـ migration

▶️ الخطوة 2: إضافة الإعلانات
   1. اذهب إلى لوحة المسؤول (/admin)
   2. انقر على تبويب "الإعلانات"
   3. اضغط "إعلان جديد"
   4. ملأ تفاصيل الإعلان:
      • العنوان والوصف
      • نوع الوسائط
      • رابط الوسائط
      • مدة التخطي
   5. اضغط "إضافة الإعلان"

▶️ الخطوة 3: عرض الإعلانات
   - ستظهر تلقائياً للمستخدمين
   - يمكن التحكم عند الحاجة

│ id                    | UUID        | معرف فريد              │
